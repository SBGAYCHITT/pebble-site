快速开始

  1. 下载 Pebble-Lunchar-{{VER}}.exe（{{SIZE}}），放到一个你找得到的地方，双击运行。
  2. Windows 可能会弹「已保护你的电脑」—— 点更多信息 → 仍要运行。这是未购买代码签名的程序都会遇到的提示，不是检测到病毒。
  3. 填一个玩家名。离线模式下这个名称会按 Minecraft 的规则算出 UUID，和服务器离线模式一致。
  4. 在「版本」页下载一个正式版或快照，然后回首页点「启动」。

第一次启动会自动下载游戏资源，视网络情况需要几分钟。之后就可以断网玩了。

配置自动更新

启动器不会偷偷联网检查更新 —— 更新源是空的，得你填一次：

  1. 打开「设置 → 系统与更新」。
  2. 在「更新源」里粘贴：
    {{ORIGIN}}/api/update/latest
  3. 点「检查更新」。有新版时会出现「下载并安装」。

下载是流式的，能看到速度和进度，随时可以取消。下完先做 SHA-256 和大小校验， 对不上就丢弃；校验通过后才会提示「立即重启安装」—— 它会等你退出启动器，再替换 exe 并重新拉起。

关键一点：清单里没有 sha256 时，启动器不会自动安装，只会显示「打开下载页」。 宁可不做这一步，也不装一个校验不了的文件。这一条是故意的，不是 bug。

数据放在哪

启动器是单文件 portable，但配置与缓存仍然需要一个固定位置，否则每次运行都像新装的：

  • 游戏目录（.minecraft）：默认在用户目录下，可在设置里改成任意路径。
  • 配置、时光机块库、实例、自带 Java：在 %APPDATA% 下与应用同名的文件夹里。
  • 下载好的更新包：同一个位置下的 updates 目录，重启后还能接着装。

在资源管理器地址栏输入 %APPDATA% 就能打开这个位置。删掉启动器 exe 不会带走存档。

系统要求

  • Windows 10 / 11，64 位。
  • 不需要预装 Java —— 启动器可以自己下载对应版本的 JDK；也可以用你已经装好的。
  • 需要网络下载游戏与资源，之后可以离线。

常见问题

杀毒软件报毒 / 无法运行

未签名的 Electron 打包程序被误报很常见。可以先核对 SHA-256 与首页的值是否一致； 一致说明文件没被动过，再加进白名单。这个项目没有购买代码签名证书， 所以「未知发布者」这个提示会一直在。

自动更新替换不了 exe

便携版运行时会把自己解压到临时目录，替换的必须是你双击的那个文件。 启动器为此用的是 PORTABLE_EXECUTABLE_FILE 而不是当前进程路径。 如果仍然失败，通常是文件被占用或位于需要管理员权限的目录（例如 C:\Program Files）， 换到普通目录或手动下载即可。

更新检查一直失败

先在浏览器打开更新源地址，应该看到一段 JSON。如果打不开，问题在地址或网络； 如果能看到 JSON 但启动器仍报错，多半是「更新源里填的不是 /api/update/latest 这个完整地址」。

两个启动器同时开着会打架吗

不会。多账户并行是分开的进程，实例之间也互相隔离；但同一个实例同时被两个进程写存档会有风险， 所以启动前会做占用检查。

接口与清单

本站同时是启动器的更新源，两个接口都不需要登录：

地址用途
GET /api/update/latest版本清单（JSON）
GET /api/update/file/<name>.exe本站托管时直接下载；否则 302 到 GitHub
GET /api/update/health自检：清单、校验值、大小是否对得上

清单字段：

{
  "version": "{{VER}}",
  "notes": "更新说明",
  "url": "安装包直链（http/https）",
  "sha256": "64 位十六进制，缺了就不自动安装",
  "size": {{SIZE_BYTES}},
  "publishedAt": "{{DATE}}"
}

版本号按数值逐段比较，所以 1.10 大于 1.9。 size 用于进度百分比，也用于「下完是否完整」的硬判据。
