第一次用

  1. 下载 {{FILE}}（{{SIZE}}），放到你找得到的地方（桌面就行），双击打开。
  2. Windows 可能弹「已保护你的电脑」—— 点更多信息 → 仍要运行。没买数字签名的软件都会这样提示，不是查出病毒了。
  3. 填一个名字。不联网的时候，游戏里显示的就是这个名字。
  4. 去「版本」页挑一个版本下载，再回首页点「启动」。

第一次启动要下载游戏文件，看网速可能要几分钟。下完之后，断网也能玩。

更新

不用你管，启动器自己会查。打开的时候查一次，之后每 6 小时查一次， 有新版本就在「设置 → 系统与更新」里告诉你，点一下就能下。

不想让它联网查，把那儿的「自动检查更新」关掉就行；想立刻看一眼，旁边有按钮。

下载时能看到速度和进度，随时可以取消。下完会先核对文件有没有下坏， 对不上就扔掉，不会装上去。核对通过后才问你要不要重启安装 —— 它等你退出启动器，再替换文件、重新打开。

有个地方是故意的：如果清单里没有文件指纹，它不会自动安装，只会给你一个下载链接。 宁可不装，也不装一个没法确认有没有被改过的文件。

想换成自己搭的更新源（一般用不到）：在「设置 → 系统与更新」的「更新源」里填 {{ORIGIN}}/api/update/latest，留空就用官方的。

我的文件都在哪

启动器本身只有一个文件，但配置和缓存要有地方放，不然每次打开都像新装的：

  • 游戏目录（.minecraft）：默认在你的用户文件夹里，设置里可以改到别的盘。
  • 设置、存档备份、实例、自带的 Java：在 %APPDATA% 下一个叫 Pebble Launcher 的文件夹里。
  • 下好的更新包：同一个文件夹里的 updates，这次没装，下次打开还能接着装。

在资源管理器地址栏输入 %APPDATA% 就能打开。删掉启动器那个 exe，不会把存档一起删掉。

电脑要求

  • Windows 10 / 11，64 位。
  • 不用自己装 Java —— 启动器能帮你下对应版本；你电脑里已经有了也能直接用。
  • 第一次要联网下载游戏文件，之后可以断网玩。

遇到问题

杀毒软件报毒 / 打不开

没签名的程序被误报很常见。可以先核对一下文件指纹和首页上那串是不是一样： 一样就说明文件没被动过，加进白名单就行。这个项目没买数字签名证书， 所以「未知发布者」这个提示会一直在。

自动更新装不上

多半是文件被占用，或者放在了 C:\Program Files 这种需要管理员权限的地方。 把启动器挪到桌面或文档里再试，或者直接重新下载一份。

检查更新一直失败

先用浏览器打开下面这个地址，应该能看到一段文字（JSON）： {{ORIGIN}}/api/update/latest。 打不开就是地址或网络的问题；打得开但启动器还报错，通常是「更新源」里少填了后面的 /api/update/latest。

两个启动器同时开着会打架吗

不会。不同账号是分开的进程，实例之间也互不影响。但同一个实例同时被两个进程写存档有风险， 所以启动前会先检查有没有被占用。

给爱折腾的人

本站顺便也是启动器的更新源，下面这几个地址都不用登录：

地址用途
GET /api/update/latest最新版本信息（JSON）
GET /api/update/file/<文件名>本站有包就直接下，没有就跳到 GitHub
GET /api/update/health自检：版本信息、指纹、文件大小对不对得上

版本信息长这样：

{
  "version": "{{VER}}",
  "notes": "这版改了什么",
  "url": "安装包下载地址",
  "sha256": "文件指纹，缺了就不自动安装",
  "size": {{SIZE_BYTES}},
  "publishedAt": "{{DATE}}"
}

版本号是按数字一段段比的，所以 1.10 比 1.9 新。 size 用来算下载进度，也用来判断有没有下完整。
